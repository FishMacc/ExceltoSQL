# ExceltoSQL

Convert Excel worksheets into SQL statements on Windows.

`ExcelToSQL_2.0.exe` reads an Excel file and generates SQL output such as `INSERT` or `CREATE TABLE` statements, so you can move spreadsheet data into a database quickly.

> **Note:** This repository contains the compiled Windows binary only. The source code is not included.

## Download

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/FishMacc/ExceltoSQL.git
   ```
2. Run `ExcelToSQL_2.0.exe`.

No separate installer is required.

## Usage

1. Start `ExcelToSQL_2.0.exe`.
2. Select the Excel file you want to convert.
3. Copy the generated SQL or save it as a `.sql` file.
